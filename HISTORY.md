## Краткое описание

**ДАВО "Заря"** — децентрализованная автономная внутрипартийная организация. Распределённое программное обеспечение для формализации, наблюдения и анализа мнения партии "Рассвет" через блокчейн-голосование и статистические методы. Система реализует математическую модель мнения партии как пары матриц случайных величин (количественных и категориальных), обновляемых через DAO-голосования согласно Уставу партии.

Документ был адресован секретарю РО по Челябинской области Д.Д. Бурцеву как инициатива по разработке демо системы.

Проект стартовал как Solidity/Foundry-монорепозиторий. С первого коммита присутствовали все ключевые компоненты:

- **`Zarya.sol`** — монолитный главный контракт, единая точка входа
- **`Matricies.sol`** — хранилище матриц выборок $S_X$, $S_Y$
- **`Votings.sol`** — управление жизненным циклом голосований
- **`PartyOrgans.sol`** — реестр партийных органов
- **`Regions.sol`** — работа с региональными отделениями
- Скрипты развёртывания (`Zarya.s.sol`, `DeployLibs.s.sol`)
- Тесты (`Zarya.t.sol`)
- Whitepaper
- CI/CD через GitHub Actions

В репозиторий была добавлена полноценная офф-чейн инфраструктура:

**`zarya-api/`** — Java Spring Boot бэкенд:
- REST и GraphQL API (`DataController`, `RawDataController`, `ReportController`, `RpcController`)
- Чтение данных из смарт-контракта через Web3j (`Web3jContractReadService`)
- PostgreSQL-персистентность (`CategoricalCell`, `NumericalCell`, `Statement`, `Theme`, `Organ`)
- PDF-генерация отчётов (`OpenPdfBasedGeneralReportService`)
- Авторизация, rate-limiting, Thymeleaf-шаблоны
- Синхронизация состояния блокчейна (`SynchronizationService`)

**`zarya-frontend/`** — Vue.js / Nuxt фронтенд с wagmi:
- Компоненты для каждого типа голосования: числовые, категориальные, тематические, членство
- Подключение кошелька (Connect), навигация, i18n (RU/EN)
- Composables: `useVotingActions`, `useVotingScanner`, `useVotingWatcher`, `useDataExplorer`

Проект приобрёл форму полного стека: блокчейн → API → UI.
