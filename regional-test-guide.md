# Руководство оператора: Региональный тест ДАВО «Заря» — 74 РО

Документ описывает последовательность вызовов для проведения регионального теста опроса Совета регионального отделения Челябинской области партии «Рассвет».


## Условные обозначения

- **Орган**: `"74.СОВ"` — Совет регионального отделения, Челябинская область (код 74)
- **Длительность голосования**: `604800` сек = 7 дней; для тестовой сети — `60` (1 минута)
- **Кворум продакшн**: `7` из 12; **тест**: `1`
- **`votingId`**: автоинкремент с 1, нарастает строго по порядку создания


## Шаг 1: Деплой и инициализация (forge script)

Все действия выполняются одним скриптом: деплой, регистрация членов, полная схема матрицы.

```bash
MEMBERS="0xM01,0xM02,0xM03,0xM04,0xM05,0xM06,0xM07,0xM08,0xM09,0xM10,0xM11,0xM12" \
  forge script script/ZaryaUI.s.sol \
  --rpc-url <RPC_URL> \
  --broadcast \
  --sender <DEPLOYER_ADDRESS> \
  --private-key <DEPLOYER_KEY>
```

Скрипт выполняет в одном сеансе:
1. Деплой `ZaryaUI`
2. `initializeReadable` — все члены + полная схема 15 категориальных и 9 числовых вопросов
3. `proposeDecimals` для 9 числовых ячеек (каждое сразу закрывается, `quorum=1`, `duration=1s`)

После этого контракт готов к раунду ответов (Шаг 2).

> Проверка: `zaryaUI.checkMembership(0xM01, "74.СОВ")` → `true`


## Шаг 2: Раунд голосований по наполнению матрицы

Паттерн на одну ячейку:

```
votingId = zaryaUI.proposeCategoricalValue("74.СОВ", x, x, <categoryId>, <memberAddr>, 60)
zaryaUI.vote(votingId, true, "74.СОВ")
zaryaUI.executeVoting(votingId, 1, 51)
```

Для числовых — `proposeNumericalValue` вместо `proposeCategoricalValue`.

> `y = x` (диагональ матрицы) — обязательно.
