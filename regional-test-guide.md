# Региональный тест ДАВО «Заря» — 74 РО: Руководство участника

**Орган:** `"74.СОВ"` — Совет РО, Челябинская область  
**Контракт:** `ZaryaUI`  
**Участники:** председатель (деплой) + члены Совета РО (ответы)

## Роль председателя: деплой и инициализация

### 1. Подготовьте адреса всех членов Совета

Соберите Ethereum-адреса всех членов и запишите их через запятую в переменную окружения `MEMBERS`.

### 2. Задеплойте контракт и инициализируйте схему

```bash
MEMBERS="0x<адрес1>,0x<адрес2>,...,0x<адресN>" \
  forge script script/ZaryaUI.s.sol \
  --rpc-url <RPC_URL> \
  --broadcast \
  --sender <ВАШ_АДРЕС> \
  --private-key <ВАШ_КЛЮЧ>
```

Скрипт сделает автоматически:
1. Деплой контракта `ZaryaUI`
2. Регистрацию всех членов в органе `74.СОВ`
3. Полную настройку схемы — все 15 категориальных и 9 числовых вопросов с вариантами ответов

После завершения скрипт выведет адрес задеплоенного контракта. **Передайте этот адрес всем членам Совета** — он нужен им для ответов.

> Проверка: `zaryaUI.checkMembership(<адрес_члена>, "74.СОВ")` должна вернуть `true` для каждого.

## Роль члена Совета РО: подача ответов

Каждый член подаёт свои ответы **самостоятельно и независимо** по всем 24 вопросам через [ДАВО Заря](https://zarya-ui-nextjs-blond.vercel.app/) или любой другой Ethereum-клиент.

### Паттерн ответа на категориальный вопрос

```
votingId = zaryaUI.proposeCategoricalValue("74.СОВ", x, x, <ID категории>, <ВАШ_АДРЕС>, 60)
zaryaUI.vote(votingId, true, "74.СОВ")
zaryaUI.executeVoting(votingId, 1, 51)
```

### Паттерн ответа на числовой вопрос

```
votingId = zaryaUI.proposeNumericalValue("74.СОВ", x, x, <значение>, <ВАШ_АДРЕС>, 60)
zaryaUI.vote(votingId, true, "74.СОВ")
zaryaUI.executeVoting(votingId, 1, 51)
```

> Второй аргумент `x` — это всегда тот же `x` (диагональ матрицы, `y = x`).  
> `<ВАШ_АДРЕС>` — ваш собственный адрес как автора ответа.  
> `60` — длительность голосования в секундах (для тестовой сети).

На каждый вопрос — **3 транзакции**: propose → vote → execute.  
Итого на одного члена: 24 вопроса × 3 = **72 транзакции**.

## Вопросы числовой матрицы (S_X)

Используйте `proposeNumericalValue`. Аргументы: `("74.СОВ", x, x, <значение>, <ВАШ_АДРЕС>, 60)`.

| x   | Вопрос                                                                             | Ед. изм.   | decimals | Как передать значение                      |
| --- | ---------------------------------------------------------------------------------- | ---------- | -------- | ------------------------------------------ |
| 0   | Минимальные средства от спонсоров для эффективной работы РО                        | руб./год   | 2        | умножить на 100 (напр. 15000.50 → 1500050) |
| 1   | Количество сторонников РО, необходимое для узнаваемости партии                     | человек    | 0        | как есть                                   |
| 2   | Минимальные членские взносы                                                        | руб.       | 0        | как есть                                   |
| 3   | Сколько % набрал бы «Рассвет» на выборах в Государственную Думу                    | %          | 0        | как есть                                   |
| 4   | Сколько часов в неделю член РО может уделять деятельности партии                   | часов/нед  | 0        | как есть                                   |
| 5   | Сколько очных мероприятий в месяц должно организовывать РО                         | меропр/мес | 0        | как есть                                   |
| 6   | Минимальный ежемесячный бюджет РО для эффективной работы                           | руб./мес   | 0        | как есть                                   |
| 7   | Сколько сторонников нужно РО для узнаваемости в регионе                            | человек    | 0        | как есть                                   |
| 8   | Оценка работы РО за год по шкале от 1 (неэффективно) до 7 (максимально эффективно) | баллы      | 0        | как есть (от 1 до 7)                       |
